    Interface PrayerMetadata

    Detailed astronomical metadata generated during prayer calculations.

    Remarks

    Exposes precise ephemeris data (declination, equation of time, refraction) primarily used for debugging, logging, or advanced astronomical integrations. Only included if withMetadata is true in the PrayerConfig.
